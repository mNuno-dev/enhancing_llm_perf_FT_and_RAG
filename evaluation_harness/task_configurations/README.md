# Task Configurations

This directory is where the European-Portuguese task configurations and
meta Llama PT tasks used in the thesis were placed to be loaded into the
[EleutherAI lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness)
framework via the `--include_path` argument.

These configurations were developed by the
[NLX research group](https://nlx.di.fc.ul.pt/) at Faculdade de Ciências,
Universidade de Lisboa, and remain within the research group.

## Running Your Own Model on the Same Benchmarks

If you want to evaluate a model on the same European-Portuguese tasks used
in the thesis, submit it for evaluation on the HuggingFace leaderboard:

**[PORTULAN/portuguese-llm-leaderboard](https://huggingface.co/spaces/PORTULAN/portuguese-llm-leaderboard)**
